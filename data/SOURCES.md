# Data sources

## route.gpx

Track geometry for a real, publicly viewable route named **"5K Run for the Cure"** in Ottawa, ON,
Canada — the CIBC Run for the Cure course, a Canadian Cancer Society breast cancer fundraiser held
annually in multiple Canadian cities including Ottawa.

- Source: MapMyRun public route page, `https://www.mapmyrun.com/routes/view/23823300` (route ID
  `23823300`), retrieved 2026-08-05.
- Reported distance: 5035.93 m (~5 km), 48 track points with elevation.
- This is route *geometry* only (a loop shape), not a real athlete's real activity — no pace, heart
  rate, timestamps, or any other personal data was taken from the source. `route.gpx` in this
  directory contains only `<trkpt>` latitude/longitude/elevation, re-derived from the public page's
  embedded route data and re-emitted as a standalone GPX 1.1 file.
- Used purely as a realistic, real-world loop shape for the synthetic sample dataset generated by
  `generate_sample_data.py` — see `docs/plan.md` for how it's used.
