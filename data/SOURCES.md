# Data sources

## route_running.gpx

Track geometry for a real, publicly viewable route named **"5K Run for the Cure"** in Ottawa, ON,
Canada — the CIBC Run for the Cure course, a Canadian Cancer Society breast cancer fundraiser held
annually in multiple Canadian cities including Ottawa.

- Source: MapMyRun public route page, `https://www.mapmyrun.com/routes/view/23823300` (route ID
  `23823300`), retrieved 2026-08-05.
- Reported distance: 5035.93 m (~5 km), 48 track points with elevation.
- This is route *geometry* only (a loop shape), not a real athlete's real activity — no pace, heart
  rate, timestamps, or any other personal data was taken from the source. `route_running.gpx` in
  this directory contains only `<trkpt>` latitude/longitude/elevation, re-derived from the public
  page's embedded route data and re-emitted as a standalone GPX 1.1 file.
- Used purely as a realistic, real-world loop shape for the synthetic sample dataset generated by
  `generate_sample_data.py` — see `docs/plan.md` for how it's used.
- Originally named `route.gpx`; renamed 2026-08-05 when `route_bike.gpx` was added, to keep the
  two sports' routes unambiguous.

## route_bike.gpx

Track geometry for the real, official **"2026 Tour de Victoria 80km"** road-cycling route in
Victoria, BC, Canada — an organized charity/community cycling event (Tour de Victoria).

- Source: public RideWithGPS route page, `https://ridewithgps.com/routes/48156781`, downloaded
  2026-08-05 as GPX directly from that page (unlike `route_running.gpx`, this file is the
  organizer's own published GPX, not reconstructed from an embedded API response).
- Reported distance: ~77 km actual (event is named for its nominal 80 km), 733 m elevation gain,
  1832 track points with elevation. Road surface, 100% paved per the source page.
- This is route *geometry* only — the file also contains the source page's `<wpt>` aid-station
  waypoints (food/hydration/mechanical support stops), which this repo's generator ignores; only
  the `<trk>`/`<trkpt>` path is used.
- Used as the loop for `generate_sample_data_bike.py`'s four simulated September 2026 rides — see
  `docs/plan.md` for how it's used.

## Real reference files (not committed)

While building the cycling generator, a real ride (`routes/2026-08-05-13-53-16.fit` and its
Cordelia-imported `.sqlite`) was used *locally, read-only* to ground-truth the schema — real
Garmin device product IDs, real sport/event enum values, which fields an actual Edge 1040 +
paired Venu 4 populate. Nothing from that ride's actual data (its GPS trace, times, physiological
readings, or device serial numbers) was copied into this repo or into the generator's output.
Only structural facts about the *schema* were extracted, the same way `sql/create_tables.sql`
itself was extracted from `cordelia`'s source. Those two files stay untracked and gitignored
(`/routes/`) — see `CLAUDE.md`'s data hygiene section.
