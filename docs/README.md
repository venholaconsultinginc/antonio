# Getting started with antonio

`antonio` shows how to query a Cordelia SQLite database and produce basic reports in Python. New to
Python, or haven't installed the dependencies yet? Start with [setup](setup.md). Need a database to
work with? See [how to get one](obtaining-data.md). Otherwise pick the sport closest to your own
data and see it worked through end to end:

- [<img src="icon-running.svg" width="32" alt=""> Running](running.md)
- [<img src="icon-cycling.svg" width="32" alt=""> Cycling](cycling.md)
- [<img src="icon-kayaking.svg" width="32" alt=""> Kayaking](kayaking.md)
- [<img src="icon-strength-training.svg" width="32" alt=""> Strength training](strength-training.md)
- [<img src="icon-swimming.svg" width="32" alt=""> Swimming](swimming.md)

Or see [all six databases at a glance](example-databases.md), including the empty one and how to
verify each download.

Already have your own Cordelia database? The report scripts work against it directly; nothing in
`antonio` depends on the example data, which is there so you have something to run against before
you have your own. All six example databases are entirely fabricated, with no real person, device
or activity represented in any of them.

For Cordelia itself, what it is and how it produces the database, see
[venholaconsulting.ca/apps/help/](https://venholaconsulting.ca/apps/help/). The name "antonio" has
[a story behind it](namesake.md).
